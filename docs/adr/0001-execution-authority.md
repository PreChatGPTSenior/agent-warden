# ADR 0001 — Separate execution repository and authority

Status: Accepted for this preparation, under the user's explicit delegation.

Create a new repository from a safe application snapshot, learning-lab deterministic tools and the consolidated product baseline. Existing projects remain unchanged. The human-only directory is excluded before traversal; secrets, caches and old evidence are not imported as runtime authority.

OpenSpec proposed changes are the maintained target; the copied Word/JSON baseline is immutable provenance. This replaces the baseline's former JSON-only maintenance rule in this new repository without changing the original document. Requirements/scenarios remain together; no separate acceptance.md is authored. Generated OpenAPI remains the HTTP contract.

All application tasks start PLANNED. Root preparation verification only certifies the package; no inherited implementation, test approval or model-quality score becomes a new PASS. The original first four features are represented by foundation, catalog and generated-contract work; the complete baseline also requires management, adoption, indexing, Spring AI, streaming and release qualification.
