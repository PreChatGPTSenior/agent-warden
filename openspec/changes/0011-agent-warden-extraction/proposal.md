# Agent Warden extraction

## Why

The orchestration tooling needs independent ownership and version history while
Stone Shelter remains unchanged as its initial application example.

## What Changes

Copy the tracked orchestration baseline and supporting specifications, tests,
quality tools, skills and templates into a new repository. Preserve runtime
behavior and zero budgets. Record source provenance and outstanding coupling.

## Capabilities

### New Capabilities
- `agent-warden-extraction`: independent, traceable source extraction.

## Impact

Only the new Agent Warden folder and repository are written. No source application
changes, agents, model calls, service startup or live qualification are included.
